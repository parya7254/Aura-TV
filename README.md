# Aura-TV
Aura-TV is a smart, designed from scratch, TV box running Linux! Featuring an Allwinner H616 with 4 cores paired with 4 gigs of LPDDR4 RAM packed inside of it, it can effortlessly stream in 4K resolution at 60 frames per second (via HDMI)! Also comes with an AP6256 Wi-Fi + Bluetooth combo chip supporting Wi-Fi 5 along with Bluetooth 5 for quick streaming and high-quality sound (from a high-quality Bluetooth enabled speaker). For storage, Aura-TV contains a SATA SSD, which is connected to the processor with a SATA interface to USB interface chip, with 128 GB of storage so that you have plenty of space for apps, recordings, etc. Power is supplied via USB-C PD, so this can be used with many modern chargers/charging bricks. Includes 3 USB ports along with a SD card interface for connecting many different peripherals.
